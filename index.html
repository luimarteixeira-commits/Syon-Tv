CATÁLOGO DE METADADOS

TMDB API Read Access Token

A chave é guardada somente neste navegador/aparelho para este protótipo. Não compartilhe o token. Para uma publicação real, mova a credencial para um backend seguro e revise os termos e atribuições do TMDB.

DISPONIBILIDADE AUTORIZADA

Onde assistir

O app consulta provedores informados pelo endpoint oficial de watch providers do TMDB por título e região. Os resultados indicam disponibilidade/provedores e links oficiais quando fornecidos; não liberam reprodução dentro do SYON TV.

Sobre o TMDB

Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB. Os metadados e imagens são fornecidos pelo TMDB.

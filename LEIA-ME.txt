SYON TV — ETAPA 3: TRAILERS E PRÉVIAS OFICIAIS

Atualização para o PWA publicado no GitHub Pages.

Novidade: na página de detalhes de cada filme ou série, o aplicativo procura trailers ou teasers do YouTube catalogados no TMDB, priorizando vídeos oficiais e português quando disponíveis. O botão abre o vídeo no YouTube; não hospeda nem distribui filmes. Quando não houver vídeo, informa a indisponibilidade.

Instalação: descompacte e envie os cinco arquivos para a raiz do repositório Syon-Tv no GitHub, substituindo os arquivos existentes. Faça commit na branch main. Aguarde a publicação no GitHub Pages.

O token TMDB e os favoritos continuam armazenados localmente no navegador. Não publique o token no GitHub. Para uso comercial, consulte os termos do TMDB e dos provedores de vídeo.

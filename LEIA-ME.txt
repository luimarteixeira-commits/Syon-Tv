SYON TV — Etapa 2: Catálogo Inteligente

Novidades: gêneros selecionáveis, lançamentos nos cinemas, em breve, filmes e séries mais bem avaliados.
O visual premium, a integração TMDB, busca, detalhes e Minha Lista continuam disponíveis.

INSTALAÇÃO
1. Descompacte o ZIP no iPhone.
2. Envie os cinco arquivos para a RAIZ do repositório GitHub Syon-Tv na branch main.
3. Substitua os arquivos existentes e confirme Commit changes.
4. Aguarde GitHub Pages publicar e abra o site no Safari.
5. Se a versão anterior aparecer, feche e reabra a página; o service worker foi atualizado.

IMPORTANTE
O token TMDB já salvo no navegador não é apagado pelo envio dos arquivos.
Não inclua o token no GitHub. O app ainda é um protótipo e precisa de backend para proteger credenciais antes de lançamento público.
Os dados são fornecidos pelo TMDB; não há reprodução de vídeo integrada.
